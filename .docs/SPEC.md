# PROMPT — REFATORAÇÃO VISUAL FIEL À IMAGEM DE REFERÊNCIA

## 1. CONTEXTO
Você deverá refatorar o site existente, utilizando como referência visual a imagem armazenada na pasta `img` do projeto.

Antes de iniciar, analise a estrutura do projeto e examine detalhadamente a imagem de referência.

A imagem deverá ser a principal fonte de inspiração para toda a identidade visual do site.

## 2. OBJETIVO
Refatorar o site para reproduzir o mais fielmente possível o design apresentado na imagem de referência.

**ATENÇÃO: É OBRIGATÓRIO UTILIZAR AS CORES E OS ÍCONES PRESENTES NA IMAGEM.**

### Paleta de cores
- Identifique as cores diretamente na imagem.
- Extraia os códigos HEX das principais cores.
- Utilize as mesmas cores em fundos, textos, botões, menus, bordas, cards e elementos de destaque.
- Preserve a proporção e a combinação das cores utilizadas na referência.
- Não invente uma nova paleta de cores.
- Evite substituir as cores originais por tons semelhantes sem necessidade.

### Ícones
- Identifique todos os ícones visíveis na imagem.
- Reproduza seus formatos, estilos, cores e proporções.
- Utilize os mesmos símbolos e representações visuais.
- Preserve o estilo dos ícones, sejam eles lineares, preenchidos, minimalistas ou ilustrativos.
- Se os ícones estiverem disponíveis nos arquivos do projeto, reutilize-os.
- Caso não estejam disponíveis, utilize SVG ou outra solução adequada para reproduzir visualmente os ícones da referência.
- Não substitua ícones por emojis ou símbolos genéricos.

## 3. ELEMENTOS VISUAIS
Reproduza também:

- Tipografia e hierarquia dos textos.
- Cabeçalho e navegação.
- Botões e seus estados visuais.
- Cards e componentes.
- Bordas, sombras e arredondamentos.
- Espaçamentos e alinhamentos.
- Imagens e elementos decorativos.
- Distribuição e proporção das seções.

O objetivo é manter a mesma linguagem visual da imagem, adaptando-a ao conteúdo e às funcionalidades do site existente.

## 4. RESTRIÇÕES TÉCNICAS
- Preserve a estrutura original do projeto sempre que possível.
- Não recrie o projeto do zero sem necessidade.
- Não remova funcionalidades existentes.
- Não altere integrações ou regras de negócio.
- Evite dependências desnecessárias.
- Mantenha o código organizado e reutilizável.
- Não utilize a imagem inteira como fundo para simular o layout.
- Construa os elementos utilizando código real (HTML, CSS e JavaScript, conforme a tecnologia existente).

## 5. RESPONSIVIDADE
Garanta que o resultado funcione corretamente em computadores, tablets e smartphones, mantendo a identidade visual da referência em todos os dispositivos.

## 6. VALIDAÇÃO
Após concluir:

1. Execute o site.
2. Compare o resultado com a imagem original.
3. Confira se as cores HEX correspondem à referência.
4. Confira se os ícones foram reproduzidos corretamente.
5. Verifique alinhamentos, tamanhos e espaçamentos.
6. Teste todos os recursos existentes.
7. Corrija erros visuais e funcionais.

## 7. REGRA FUNDAMENTAL
A imagem da pasta `img` não é apenas uma inspiração genérica: ela é o PADRÃO VISUAL que deverá orientar a refatoração.

Não tome decisões estéticas que descaracterizem a referência.

**RESULTADO ESPERADO:** um site moderno, funcional e responsivo, preservando as funcionalidades originais e reproduzindo fielmente as cores, os ícones, a tipografia e a identidade visual da imagem de referência.

Antes de finalizar, apresente um resumo das alterações e dos arquivos modificados.
